# SSU_FIND

A cross-platform Flutter application for finding and managing lost and found items at SSU.

---

## 🚀 Getting Started

This project is a starting point for a Flutter application supporting **Android**, **Web**, and (optionally) **iOS**.

### Features

- Browse lost and found items
- Add new items with images and descriptions
- Claim items and contact item owners via chat
- Responsive UI for web and mobile

---

## 🛠️ Installation

**1. Clone this repo:**

```sh
git clone https://github.com/<your-username>/SSU_FIND.git
cd SSU_FIND
```

**2. Install dependencies:**

```sh
flutter pub get
```

**3. Run the app:**

- **Web:**  
  ```sh
  flutter run -d chrome
  ```
- **Android:**  
  ```sh
  flutter run
  ```
- **iOS:**  
  *(Requires a Mac with Xcode)*

---

## 🌐 Deploying to GitHub Pages (Web)

**Build for web:**

```sh
flutter build web
```

**Deploy using [peanut](https://pub.dev/packages/peanut):**

```sh
dart pub global activate peanut
peanut
```

Your app will be available at  
`https://<your-username>.github.io/SSU_FIND/`
